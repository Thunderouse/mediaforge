# MediaForge

**Портативный медиаконвертер для Windows 10/11** — видео, GIF, картинки и звук
в одном окне. Работает локально: ничего не устанавливает в систему и не отправляет
файлы в интернет.

## Скачать и запустить

| Платформа | Файл | Требования |
|---|---|---|
| Windows 10/11 x64 | `MediaForge-<версия>-portable-win64.zip` | ничего, только распаковать |
| Linux x86_64 | `MediaForge-<версия>-portable-linux-x86_64.tar.gz` | glibc 2.34+ (Ubuntu 22.04+, Debian 12+) |
| Linux aarch64 | `MediaForge-<версия>-portable-linux-aarch64.tar.gz` | glibc 2.39+ (Ubuntu 24.04+, Debian 13+) |
| macOS 14+ (Apple Silicon) | `MediaForge-<версия>-macos-arm64.zip` | `brew install ffmpeg` |

Все архивы лежат на странице [Releases](../../releases).

**Windows**

1. Распакуйте архив целиком в любую папку — например, `C:\Tools\MediaForge`.
   Важно: всю папку, а не отдельные файлы.
2. Двойной клик по **`MediaForge.exe`** — всё. ffmpeg, Python и библиотеки уже внутри.

**Linux**

1. `tar -xzf MediaForge-portable-linux-*.tar.gz` и зайдите в папку.
2. `./MediaForge.sh` (если файл не запускается — `chmod +x MediaForge.sh`).
3. Ярлык в меню приложений: `./create-shortcut.sh`.

Если система минимальная (без графических библиотек), доставьте их:
`sudo apt install libegl1 libgl1 libxkbcommon-x11-0 libxcb-cursor0 libxcb-icccm4
libxcb-image0 libxcb-keysyms1 libxcb-render-util0 libxcb-shape0`.

Установка не нужна, права администратора (root) не нужны. Ярлык делается обычным
способом: правый клик по `MediaForge.exe` → «Отправить» → «Рабочий стол
(создать ярлык)».

> Первый запуск может сопровождаться предупреждением SmartScreen об «неизвестном
> издателе» — сборка не подписана платным сертификатом. «Подробнее» →
> «Выполнить в любом случае».

## Что умеет

| Задача | Из чего | Во что |
|---|---|---|
| **Видео** | MP4, MKV, MOV, WebM, AVI, WMV, FLV, TS, M2TS, 3GP… | MP4 (H.264), MKV (H.265 / H.264), WebM (VP9), MOV, AVI |
| **Видео → GIF** | любое видео | GIF с настройкой FPS, разрешения (общий список выше) и зацикливания; память и размер — [ниже](#gif-память-и-размер) |
| **Звук из видео** | видео и аудио | MP3, M4A (AAC), WAV, FLAC, Opus, OGG |
| **Картинки** | PNG, JPEG, WebP, AVIF, BMP, TIFF, GIF, ICO, HEIC… | PNG, JPEG, WebP, AVIF, TIFF, BMP, GIF, ICO, PDF |

Для изображений есть масштабирование: проценты (25–400 %) или **точный размер
в пикселях** («Свой размер, px») с сохранением пропорций и флажком, который это
сохранение отключает. Поля связаны: вводите ширину — высота пересчитывается
сразу. Явные числа применяются всегда, а флажок «Разрешение может увеличивать»
относится только к списку «Разрешение», плюс **апскейл** — флажок «Разрешить
увеличение» (по умолчанию картинка только уменьшается). Метод ресемплинга:
Lanczos (по умолчанию), бикубический или «ближайший» для пиксель-арта.

Ещё:

- перетаскивание файлов и папок прямо в окно, папки читаются рекурсивно;
- **вырезание фрагмента** — у каждого файла свой: поля «С начала» и «По» живут
  в предпросмотре рядом с полоской кадров, формат `1:30`, `00:01:30.5` или
  просто секунды (`90`); пустое поле = начало/конец файла. Работает для видео,
  GIF и извлечения звука, обрезка одного файла не задевает остальные;
- **проверка обновлений** — кнопка ↻ в шапке: один запрос к GitHub по нажатию
  (никаких фоновых проверок и телеметрии), показывает номер новой версии и
  открывает страницу релиза;
- **предпросмотр** — отдельная вкладка: кадр, картинка или волновая форма,
  полоска кадров и ползунок позиции. Границы фрагмента тянутся ручками прямо
  на полоске, дублируются полями «С начала / По» и применяются к тому файлу,
  который открыт в предпросмотре;
- **проигрывание фрагмента** — кнопка ▶ в предпросмотре проигрывает выделенный
  кусок по кругу (12 кадров/с, без звука). Полноценный плеер потребовал бы
  QtMultimedia и +200 МБ кодов в сборке;
- у каждого файла свой формат, плюс «Всем файлам» для массовой смены;
- качество: **Качество / Баланс / Размер** и ограничение разрешения (4K…480p).
  Под кнопками — подсказка с фактическими значениями (CRF и пресеты видео, CQ
  у GPU-кодировщиков, quality картинок); для GIF и извлечения звука блок
  скрыт полностью, потому что качество там ни на что не влияет;
- прогресс и скорость по каждому файлу, отмена на лету;
- **щадящий режим** — половина потоков CPU и по одному файлу за раз, если нужно
  работать параллельно и не мешать другим программам;
- **GPU-ускорение** (NVENC / Quick Sync / AMF): программа проверяет, что кодировщик
  реально работает, иначе тихо остаётся на CPU;
- светлая и тёмная тема; размер окна и настройки запоминаются.

## Как пользоваться

1. Перетащите файлы или папку в окно — либо нажмите на пунктирную область.
   Двойной клик по файлу открывает его в «Предпросмотре».
2. Справа выберите качество и разрешение. Для GIF появятся настройки анимации,
   для звука — битрейт.
3. В строке каждого файла выберите целевой формат. По умолчанию подставляется
   разумный: PNG/WebP для картинок, MP4 для видео, MP3 для звука.
   Нужен только кусок видео — откройте файл в предпросмотре и задайте «С начала»
   и «По» (например `0:15` — `0:45`) или потяните ручки на полоске кадров;
   в строке файла появится метка `✂ 0:15–0:45`, а прогресс будет считаться
   по длине фрагмента. Фрагмент свой у каждого файла — в очереди могут быть
   разные куски разных видео.
4. Нажмите **«Конвертировать»**. Результаты появятся рядом с исходными файлами,
   если в блоке «Куда сохранять» не указана другая папка.

Если имя занято, к файлу добавится `(1)`, `(2)` — исходники не затираются,
пока не включён флажок «Перезапись».

### Горячие клавиши

| Клавиши | Действие |
|---|---|
| `Ctrl+O` | добавить файлы |
| `Ctrl+Enter` | начать конвертацию |
| `Esc` | остановить |
| `Ctrl+L` / `Ctrl+D` | светлая / тёмная тема |

## Настройки и следы в системе

Сборка портативная: настройки и геометрия окна лежат в папке `data\` **рядом
с программой**, поэтому её можно переносить на флешке вместе с настройками.
В реестр ничего не пишется, службы не создаются, после закрытия окна процессов
не остаётся. Удаление — просто удалить папку.

## Если что-то не работает

| Симптом | Что делать |
|---|---|
| SmartScreen ругается / антивирус удалил `MediaForge.exe` | запустить `MediaForge.cmd` — он делает то же самое |
| Окно не открывается | запустить `MediaForge-debug.cmd`: в консоли будет текст ошибки |
| «Рядом с MediaForge.exe нет папки python» | архив распакован частично — распакуйте целиком |
| Видео не открывается после конвертации | выберите MKV · H.264 или MP4 (H.264) |
| Нужно проверить окружение | `MediaForge-check.cmd` покажет версии Python, PySide6 и ffmpeg |

Подробный лог ошибок приложения пишется в `%TEMP%\mediaforge-error.log`.

## Командная строка

Для автоматизации есть консольный режим (из исходников):

```bash
python -m mediaforge.cli video.mp4 --to gif --fps 12 -r 480
python -m mediaforge.cli photo.png --to avif --quality small --out ./out
python -m mediaforge.cli movie.mkv --to mp3 --bitrate 320k
python -m mediaforge.cli ./photos --to webp -r 1080 --gentle
```

## Другие системы и сборка из исходников

**macOS.** Портативного архива пока нет: сборка под macOS требует самой macOS
(PyInstaller не кросс-компилирует, а для arm64 нужна хотя бы ad-hoc подпись
бинарников). Из исходников запускается так:

```bash
brew install ffmpeg python@3.12
pip install -r requirements.txt
python -m mediaforge
```

Готовый `.app` собирается на Mac скриптом `./build_unix.sh`; для раздачи другим
людям понадобится подпись Developer ID и нотаризация Apple.

**Linux (из исходников).** `./start.sh` либо
`pip install -r requirements.txt && python -m mediaforge`, нужен системный `ffmpeg`.

Для разработчика — архитектура, тесты, сборка `.exe`, portable-архивов для
Windows и Linux: **[docs/DEVELOPMENT.md](docs/DEVELOPMENT.md)**.

## Нагрузка на систему

Интерфейс занимает ~80 МБ ОЗУ и почти не грузит CPU в покое. Тяжёлая работа идёт
в отдельном процессе `ffmpeg`, одновременно конвертируется 1–2 файла
(в «щадящем режиме» — один). Никакой телеметрии и сетевых запросов.

### GIF: память и размер

GIF собирается в два прохода: сначала `ffmpeg` строит палитру по кадрам, потом
кодирует с ней. Палитра — 256 цветов, сглаживание и прочие настройки от этого
не меняются.

**Память.** Второй проход берёт готовую палитру из файла, поэтому кадры в
оперативной памяти не накапливаются: на типичном 480p это порядка 100–150 МБ,
и от длины исходника это число не зависит. Раньше обе стадии шли одной
командой, и память росла вместе с длительностью — на 40-секундном 720p
доходило до 1,1 ГБ, на длинных видео — до 6 ГБ.

**Размер файла.** GIF хранит каждый кадр отдельно, без межкадрового сжатия,
поэтому результат растёт от длительности, FPS и разрешения, а также от
«шумности» картинки: градиенты, мелкий текст и быстрая смена планов весят
больше статичных сцен. Конкретные мегабайты заранее не назвать — зависит от
содержимого.

**Разумные пределы:**

- вырежьте фрагмент: обрезка применяется до чтения файла и ограничивает сразу
  время кодирования, память и размер результата — для GIF это главный рычаг;
- 10–15 fps достаточно для интерфейсных демонстраций, 25–30 нужны только там,
  где важно плавное движение;
- 480p — практичный потолок: выше GIF растёт в разы, а разница на глаз
  невелика;
- если ролик длиннее ~30 секунд или важнее качество, берите WebM или MP4:
  при том же разрешении файл получается меньше.
