MediaForge 1.0 — портативный медиаконвертер (Windows 10/11 x64)
=============================================================

ЗАПУСК
  1. Распакуйте архив целиком в любую папку (например, C:\Tools\MediaForge).
     Важно: распаковывать нужно всю папку, а не отдельные файлы.
  2. Двойной клик по MediaForge.exe — обычное приложение, без консоли.
  3. Ярлык на рабочий стол: правый клик по MediaForge.exe → «Отправить» →
     «Рабочий стол (создать ярлык)».

MediaForge.exe — не самораспаковывающийся архив, а нативный лаунчер: он
запускает интерпретатор и код из соседних папок (python\, app\, bin\).
Поэтому папку нельзя «почистить», вытащив один exe.

Ничего не устанавливается: ни служб, ни записей в реестре, ни фоновых процессов
после закрытия окна. Удаление — просто удалить папку.
Настройки и геометрия окна хранятся в папке data\ рядом с программой
(поэтому сборка переносится на флешке вместе с настройками).

ЧТО ВНУТРИ
  MediaForge.exe        — лаунчер (двойной клик)
  python\               — встроенный Python 3.11 (ничего доустанавливать не нужно)
  app\                  — код программы и библиотеки (PySide6, Pillow)
  bin\                  — ffmpeg.exe и ffprobe.exe (вся обработка медиа)
  data\                 — создаётся при первом запуске: настройки
  MediaForge.cmd        — тот же запуск, если exe заблокирован антивирусом
  MediaForge-debug.cmd  — запуск с консолью и текстом ошибки
  MediaForge-check.cmd  — проверка окружения: версии Python, PySide6, ffmpeg

ВОЗМОЖНОСТИ
  • Видео → MP4 (H.264), MKV (H.265/H.264), WebM (VP9), MOV, AVI
  • Видео → GIF (FPS, ширина, зацикливание)
  • Извлечение звука → MP3, M4A, WAV, FLAC, Opus, OGG
  • Картинки → PNG, JPEG, WebP, AVIF, TIFF, BMP, GIF, ICO, PDF
  • Перетаскивание файлов и папок, прогресс по каждому файлу, отмена
  • Светлая и тёмная темы, щадящий режим, GPU-ускорение (если есть)

ГОРЯЧИЕ КЛАВИШИ
  Ctrl+O — добавить файлы     Ctrl+Enter — конвертировать
  Esc — остановить            Ctrl+L / Ctrl+D — светлая / тёмная тема

ЕСЛИ АНТИВИРУС/ЗАЩИТА WINDOWS РУГАЕТСЯ
  SmartScreen может предупредить о неизвестном издателе — это нормально для
  неподписанной сборки: «Подробнее» → «Выполнить в любом случае».
  Если антивирус удалил exe как «неизвестный», запустите MediaForge.cmd —
  он делает то же самое и обычно не вызывает вопросов.

ЕСЛИ ЗАПУСК НЕ УДАЛСЯ
  Запустите MediaForge-debug.cmd — в консоли будет текст ошибки; ошибки
  приложения дополнительно пишутся в %TEMP%\mediaforge-error.log.
  Чаще всего причина в том, что папки python, app и bin не лежат рядом с
  MediaForge.exe (архив распакован частично).

ffmpeg распространяется под своей лицензией (GPL), см. bin\ — исходники на
https://ffmpeg.org. Оболочка MediaForge — MIT.
